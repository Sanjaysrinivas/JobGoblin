Product Direction

What JobGoblin is

A private, self-hosted workspace for managing a job search from resume facts through applications, follow-ups, outreach drafts, and interview preparation.

What JobGoblin is not

It is not an auto-apply system, spam tool, silent email sender, recruiter bot, LinkedIn automation tool, or credential invention machine.

Where We Are Now

Merged MVP

Resumes, jobs, contacts, applications, dashboard, profile builder, follow-up reminders, analysis, cover letters, and outreach drafts exist.

Private by design

Invite-only auth, user scoping, no silent external actions, and review-only drafts are core product constraints.

Needs proof

The merged app still needs integrated verification, real Ollama runtime checks, OAuth validation, and tunnel smoke testing.

Final Application State

The final app is a local-first job-search command center. A user can maintain a master profile, manage resume versions, save jobs, analyze fit, generate grounded cover letters and tailored resume drafts, track applications and contacts, prepare outreach manually, plan follow-ups, and prepare for interviews.

Every generated artifact remains editable and traceable to user-provided facts. Every external action remains explicit and human-reviewed.

Definition Of Done

JobGoblin is done when the complete job-search loop works privately from resume/profile to analysis, tailored drafts, application tracking, follow-up, outreach prep, and interview prep, with real local AI, clear operations docs, strong user isolation, and no silent external actions.
